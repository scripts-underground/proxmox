OliveTin gives safe and simple access to predefined shell commands from a web interface. It turns scripts and routine actions into clickable buttons, with argument inputs, ACLs, and audit logging.

## Notes

- Runs inside an existing LXC container (Debian/Ubuntu only)
- Update with: `update-olivetin` — Uninstall with: `uninstall-olivetin`
- Re-running the installer offers update/uninstall via the framework guard
