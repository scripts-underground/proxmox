Usenet downloader focused on efficiency and performance. Automates downloading, checking, repairing, and extracting NZB files, optimized to run well on lower-powered devices.

## Notes

- Access the web UI at `http://{ip}:6789`
- Default credentials: `nzbget` / `tegbzn6789`
- Configuration is stored at `/var/lib/nzbget/nzbget.conf`
