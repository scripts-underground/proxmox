CasaOS - A simple, easy-to-use, elegant open-source Personal Cloud system.

## Notes

- CasaOS uses Docker to manage apps. The `setup_docker` function handles Docker installation.
- Access the web UI at `http://<ip>` to complete setup.
- The installer is sourced from a third-party (get.casaos.io). Review the installer code before running.
