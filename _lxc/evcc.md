EVCC is an open-source tool that manages EV charging, prioritizing solar energy use to reduce costs and optimize charging times. It supports various EVs and chargers, adjusting power automatically based on real-time data.

## Notes

- To configure evcc, place a `evcc.yaml` config file in `/etc`
- Access the web UI at `http://<ip>:7070`
