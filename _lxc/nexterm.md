Nexterm is an open-source server management software for SSH, VNC and RDP. It bundles a web interface, file management, monitoring, and team collaboration with two-factor authentication, OIDC SSO, and encrypted credential storage.

## Notes

- Access the web UI at `http://{ip}:6989`.
- The first boot may take a moment while the server initializes.
