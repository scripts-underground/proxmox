Open-source task and project management application. Tracks tasks, deadlines, and progress in a clean Web UI.

## Notes

- Database stored at `/opt/tududi-db/production.sqlite3`.
- Uploads stored at `/opt/tududi-uploads`.
- Configure `TUDUDI_ALLOWED_ORIGINS` in `/opt/tududi/backend/.env` when using behind a reverse proxy.
