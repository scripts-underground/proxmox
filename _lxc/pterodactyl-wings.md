Pterodactyl Wings is the server daemon for the Pterodactyl game panel
management system. It handles running and managing game servers using
Docker containers.

## Notes

- Access the web UI at `http://{ip}:8080` to complete setup.
- Requires a running Pterodactyl Panel instance to connect to.
