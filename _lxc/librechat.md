Enhanced ChatGPT clone with multi-model AI support, agents, tools, and code interpreter.
## Notes
- Configure AI providers by editing `/opt/librechat/.env`.
- RAG API is installed at `/opt/rag-api/` for document retrieval.
- Default credentials: set via `/opt/librechat/.env` (ALLOW_REGISTRATION enabled).
