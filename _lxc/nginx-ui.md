Nginx UI is a web-based interface for managing Nginx servers. It provides features such as real-time server monitoring, configuration management, SSL certificate management, and more.

## Notes

- Access the web interface at `http://<your-ip>:9000`
- On first launch, you will need to create an admin account
- Default HTTP challenge port is 9180
