End-to-end encrypted collaborative office suite. Real-time document editing with full privacy.

## Notes

- After installation, run `systemctl status cryptpad.service` to get the admin token URL.
- Can optionally install OnlyOffice components instead of CKEditor during install.
- Config file: `/opt/cryptpad/config/config.js`
