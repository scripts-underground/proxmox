Modern selfhosted media management system. Manage, discover, and automate your TV and movie collection in a single interface.

## Notes

- Access the web UI at `http://<ip>:8000` to start managing your media library.
- Config file is at `/opt/mm/config/config.toml`.
- Default media directories are in `/opt/mm/media/`.
- Set `var_admin_email` environment variable to set the initial admin email (default: `admin@example.com`).
