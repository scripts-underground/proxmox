JavaScript-based Matter controller server (successor to Python Matter Server). Provides WebSocket API compatible with Home Assistant Matter integration.
## Notes
- For Matter-over-Thread (Thread Border Router), IPv6 must be enabled in the LXC container.
- This is a Beta version. Not yet officially CSA-certified.
