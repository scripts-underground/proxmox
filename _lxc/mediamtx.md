MediaMTX is a ready-to-use SRT / WebRTC / RTSP / RTMP / LL-HLS media server and media proxy that allows you to read, publish, proxy, record and playback video and audio streams.

## Notes

- Config file is located at `/opt/mediamtx/mediamtx.yml`
- Supports hardware acceleration for Intel iGPU, AMD GPU, and NVidia GPU
- After updates, the config file is preserved from being overwritten
