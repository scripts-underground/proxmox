A fast, modern web interface for qBittorrent. Supports managing multiple qBittorrent instances from a single, lightweight application with features like cross-seeding, automations, orphan scanning, and backups.

## Notes

- Access the web UI at `http://<ip>:7476` to complete setup.
- Qui runs as a single binary — no additional dependencies required.
- Configuration is stored at `/root/.config/qui/config.toml`.
