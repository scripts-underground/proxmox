Ownfoil is a Nintendo Switch library manager that turns your library into a fully customizable and self-hosted Shop, supporting multiple clients including Tinfoil, Cyberfoil, and Sphaira.

## Notes

- Ownfoil requires an admin user to be created to enable Authentication. Go to the Settings tab to create a first user that will have admin rights.
- More CPU/RAM may be required depending on library size and number of concurrent users.
