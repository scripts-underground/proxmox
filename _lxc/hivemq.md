HiveMQ CE is a Java-based open source MQTT broker that fully supports MQTT 3.x and MQTT 5.

## Notes

- To check if HiveMQ is listening on the default port: `lsof -i :1883`
- Config file: `/opt/hivemq/conf/config.xml`
