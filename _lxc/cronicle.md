Multi-server task scheduler and job runner with a web UI. Schedule, monitor, and manage cron-like jobs across worker nodes with real-time logging and alerts.

## Notes

- Access the web UI at `http://<ip>:3012`
- Default port is 3012 (HTTP)
- Worker installation is available via the update menu after primary setup
