Sync-in Server: sovereign platform for file storage, sharing, synchronization, and collaboration.

## Notes

- Access the web UI at `http://<ip>:8080` to complete setup.
- The installation script will prompt you to create an admin user interactively.
- Uses MariaDB for data storage.
- Data files are stored in `/opt/sync-in/data`.
