Open-source web application for comprehensive vehicle management. Easily track fuel consumption, maintenance, insurance, and regulatory documents for all your vehicles in one place.

## Notes

- Default credentials: no username, password `123456`.
- Update `/opt/tracktor.env` if using behind a reverse proxy.
- Database stored at `/opt/tracktor-data/tracktor.db`.
