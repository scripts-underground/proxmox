Modern UI for Ansible, Terraform, OpenTofu, Bash, and Pulumi. Run automation tasks with a friendly web interface.

## Notes

- Default admin credentials are stored in `~/semaphore.creds` inside the container.
- Access the web interface at `http://<container-ip>:3000`.
