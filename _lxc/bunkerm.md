All-in-one self-hosted MQTT broker management platform bundling Eclipse Mosquitto with a full-featured web dashboard, smart anomaly detection, local automation agents, and optional AI assistant.

## Notes

- MQTT broker is available on port 1900. Default MQTT credentials are username 'bunker' / password 'bunker' — change them after first login.
- Create your admin account on first visit to the web UI at port 2000.
