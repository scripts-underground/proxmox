Media request management and discovery tool for the Plex ecosystem. Allows users to search, request, and manage content for their Plex server.

## Notes

- Access the web UI at `http://<ip>:5055`
- Requires a running Plex instance to function
- Configuration is stored in `/opt/overseerr/config`
