Web-based GUI for managing Asterisk PBX. Provides extension management, IVR, call routing, voicemail, CDR reporting, and module-based feature expansion.

## Notes

- Install uses the official FreePBX install script from [sng_freepbx_debian_install](https://github.com/FreePBX/sng_freepbx_debian_install).
- No update function is provided — reinstall to get the latest version.
- Default web interface is on port 80.
