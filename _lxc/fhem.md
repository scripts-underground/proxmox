GPL'd Perl server for house automation. Supports HomeMatic, Z-Wave, EnOcean, KNX, and 430+ modules for switching, heating, weather, and sensors.
## Notes
- Access the web interface at port 8083.
- Installed from the FHEM nightly repository.
- Avahi daemon is included for mDNS discovery.
