Prometheus Proxmox VE Exporter exposes Proxmox VE metrics in Prometheus format via a simple HTTP endpoint.

## Notes

- Access the web UI at `http://<ip>:9221`.
- Edit the config file at `/opt/prometheus-pve-exporter/pve.yml`.
