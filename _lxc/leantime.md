A goals-focused project management system for non-project managers. Combines strategy, planning, and execution with task management via kanban boards, gantt charts, table, list, and calendar views.

## Notes

- Access the web UI at `http://<ip>/install` to complete the initial setup.
- Runs on Apache with PHP 8.4 FPM and MariaDB.
- Supports LDAP/SSO/OIDC, 2FA, and integrations via API.
