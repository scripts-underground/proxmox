Lightweight, self-hosted knowledge base and note-taking platform. Write Markdown notes, build a graph of linked knowledge, and search full-text.
## Notes
- Notes are stored as plain files in /opt/notediscovery/data.
- Configuration is in /opt/notediscovery/config.yaml.
