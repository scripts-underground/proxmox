Dolibarr ERP CRM is a modern software package to manage your company or foundation's activity (contacts, suppliers, invoices, orders, stocks, agenda, accounting, ...). It is an open source Web application (written in PHP) designed for businesses of any sizes, foundations and freelancers.

## Notes

- Access the web UI at `http://<ip>` to complete setup.
- Database credentials are stored in `~/dolibarr.creds`.
- Config file: `/usr/share/dolibarr/htdocs/conf/conf.php.example`.
