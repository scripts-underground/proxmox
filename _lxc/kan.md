Open-source project management alternative to Trello. Features board visibility controls, workspace members, Trello imports, labels, filters, comments, activity logs, and templates.

## Notes

- Access the web UI at `http://<ip>:3000` to log in or sign up.
- The first user to sign up becomes the admin.
- Requires PostgreSQL and Node.js 22 with pnpm.
- Redis is optional (for rate limiting).
